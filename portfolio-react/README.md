# Portfolio MMI — React + TypeScript + three.js

```bash
npm install
npm run dev      # http://localhost:5173
npm run build    # vérifie les types + build dans dist/
```

Modifie tes contenus dans `src/data.ts`.

## Déployer sur Vercel
1. Pousse le dossier sur GitHub.
2. Sur vercel.com → Add New Project → importe le dépôt.
3. Vercel détecte Vite tout seul (build : `npm run build`, sortie : `dist`). Clique sur Deploy.
